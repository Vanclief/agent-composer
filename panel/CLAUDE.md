# panel/: the agc control panel

React 19 + TypeScript (strict) + Vite, Tailwind v4, shadcn/ui (new-york, zinc),
lucide-react, TanStack Query, react-router v7, xterm.js. agc embeds the build
(`panel/dist`) and serves it at `/panel/`; the API is same origin under `/api`.

Several agents build screens here in parallel. Stay inside your directory and
the panel stays conflict-free.

## Who owns what

| Path                                                                                                                                                             | Owner               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- |
| `src/features/tasks/` (`TasksPage`, `TaskPage`, `SpecTab`) + `tests/tasks.spec.ts`                                                                               | tasks feature       |
| `src/features/create-task/` (`CreateTaskDialog`) + `tests/create-task.spec.ts`                                                                                   | create-task feature |
| `src/features/terminals/` (`TerminalsTab`) + `tests/terminals.spec.ts`                                                                                           | terminals feature   |
| `src/features/messages/` (`MessagesTab`, `MessagesPage`) + `tests/messages.spec.ts`                                                                              | messages feature    |
| everything else: `src/api/`, `src/components/`, `src/shell/`, `src/App.tsx`, `src/main.tsx`, `mock/`, `scripts/`, `tests/shell.spec.ts`, configs, `package.json` | foundation (shared) |

- The files in `src/features/` are placeholders. Replace them freely, but keep
  the exported component names and props: `App.tsx` and `TasksPage` import
  them. `TaskPage` must keep rendering `<Outlet/>` for its tabs.
- Put helpers, sub-components and feature-only hooks inside your own feature
  directory.
- Shared files (`src/api/hooks.ts`, `mock/server.ts`, `src/components/*`) may
  need a small addition, such as a missing hook or mock behavior. Append new
  code only: never reorder, reformat or rename what is there, so parallel
  edits merge cleanly. Mention each shared-file change in your report.
- Don't edit `src/components/ui/` (generated by shadcn) or
  `src/api/schema.d.ts` (generated by `npm run types`).
- **No new dependencies without asking.** Everything planned is installed.
  `npx shadcn add <component>` counts as a dependency change.

## Routes

Basename `/panel`. Defined in `src/App.tsx` (foundation).

| Route                             | Component                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------- |
| `/`                               | redirects to the first page of the last used mode (Work → `/tasks`, Think → `/think/beliefs`; `src/shell/mode.tsx`) |
| `/think`                          | redirects to `/think/beliefs`                                                 |
| `/think/{beliefs,decisions,rules,evidence}/:id?` | Think mode pages (`src/features/think/`), read-only, `:id` opens the detail pane |
| `/tasks`                          | `TasksPage`; "New task" opens `CreateTaskDialog`                              |
| `/tasks/:name`                    | `TaskPage`, redirects to `terminals`                                          |
| `/tasks/:name/terminals`          | `TerminalsTab`                                                                |
| `/tasks/:name/messages`           | `MessagesTab` (channel `#<name>`)                                             |
| `/tasks/:name/spec`               | `SpecTab`                                                                     |
| `/messages`, `/messages/:channel` | `MessagesPage`; `:channel` has no `#` (`/messages/review-42` is `#review-42`) |

Each page sets the top bar title with `usePageTitle('…')` from
`@/shell/page-title`.

## Design rules

- Follow `/Users/vanclief/.claude/skills/rtsdesign/SKILL.md`: icons, slots,
  chips and numbers instead of sentences; explanations go in tooltips.
- **One icon per concept:** import from `@/components/concept-icons`
  (`conceptIcons.task`, `.cpu`, `.memory`, `.image`, `.repo`, `.ref`,
  `.setup`, `.secret`, `.env`, `.volume`, `.channel`, `.savedSpec`,
  `.terminal`, `.message`, `.human`, `.raw`). Never pick a different Lucide
  icon for one of these. A new concept is added there first.
- **Statuses are verbatim:** render `<StatusPill status={task.status}
detail={task.status_error} />`. Never derive, map or relabel a status in
  the UI. If a status is wrong, the backend has to change.
- **Empty states say why in place:** use `<EmptySlot onAdd={…} label="Add …" />`
  for a fillable slot, or `<EmptySlot reason="Task stopped" />` when it can't
  be filled. A disabled control says why in its own label ("Create: needs a
  title"), never only in a tooltip.
- **Backend errors are shown verbatim:** every API failure is an `ApiError`
  whose `message` is the server's text. Render it with
  `<ErrorText error={query.error} />` (or `errorMessage(e)`), in place,
  never rephrased, and never only as a toast.
- `<IconChip icon={conceptIcons.memory}>4 GB</IconChip>` for icon + mono
  values, paths and ids.
- Compact zinc look, dark by default (light via the sidebar toggle). Use the
  shadcn components in `@/components/ui` (button, card, badge, dialog,
  alert-dialog, input, textarea, label, tabs, tooltip, toggle, toggle-group,
  switch, select, separator, scroll-area, dropdown-menu, sonner, skeleton,
  command).

## API

- `@/api/client`: `api` (typed openapi-fetch client for everything in
  `docs/openapi.yaml`), `unwrap(api.GET(…))`, `apiFetch` for routes not in
  the spec, `ApiError`, and the `Task`, `TaskSpec`, `CreateTaskRequest`,
  `SavedSpec` and `Secret` types.
- `@/api/hooks`: `useTasks` (polls every 5s), `useTask(nameOrId)`,
  `useCreateTask`, `useStopTask`, `useStartTask`, `useDeleteTask`,
  `useSpecs`, `useSpec`, `useSaveSpec`, `useDeleteSpec`, `useSecrets`,
  `useTerminals(task, enabled)`, `useStartTerminal(task)`, `useChannels`,
  `useJoin`, `useLeave`, `usePostMessage`, and `useChannelMessages(channel)`
  (a live feed: read, then a long-poll wait loop). Query keys live only in
  `queryKeys`.
- `@/api/msg`: messaging types and calls (`/api/msg/join|leave|post|read|wait|channels`),
  hand-typed from `messaging/httpapi/httpapi.go`. Join answers 409
  `name @x is already in use` while the name is held.
- `@/api/terminals`: terminal types, `terminals.list/start`, and
  `terminalSocketURL(task, job)`. Binary frames carry bytes both ways; send
  the text frame `{"type":"resize","rows":N,"cols":N}` to resize. The server
  closes with reason `job completed` when the program exits.
- After `docs/openapi.yaml` changes, run `npm run types` and commit
  `src/api/schema.d.ts`. `npm run check` fails while it is stale.

## Commands (run in `panel/`)

First time: `npm ci && npx playwright install chromium`.

| Command                  | What it does                                                                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `npm run mock`           | Mock API on http://127.0.0.1:8790 (`-- --port N`)                                                                                                                               |
| `npm run dev`            | Vite dev server at http://localhost:5173/panel/, `/api` proxied to `VITE_API_TARGET` (default the mock on 8790; a real agc is `http://127.0.0.1:1202`)                          |
| `npm run shot -- /tasks` | Screenshot a route at 1440x900 against its own fresh mock and dev server, writes and prints `/tmp/agc-panel/<route>.png`. Flags: `--theme light`, `--out <path>`, `--wait <ms>` |
| `npm run check`          | Types drift, `tsc -b`, eslint, Playwright. Must be green before you finish                                                                                                      |
| `npm run test`           | Playwright only                                                                                                                                                                 |
| `npm run types`          | Regenerate `src/api/schema.d.ts` from `../docs/openapi.yaml`                                                                                                                    |
| `npm run build`          | Typecheck and build `dist/` (what agc embeds)                                                                                                                                   |
| `npm run format`         | Prettier (no semicolons, single quotes, width 120)                                                                                                                              |

Look at your screen with `npm run shot` and read the PNG before you report.

## Tests

- Playwright specs live in `tests/`, one file per feature (table above).
- The config starts the mock and `vite preview` of a fresh build, on ports
  derived from the checkout path, so parallel worktrees don't collide.
- Open full paths: `page.goto('/panel/tasks')`.
- All tests in a run share one mock. Don't depend on another test's
  changes. When a test creates something, give it a unique name.
- The placeholder headings ("TasksPage", "TerminalsTab", …) are only test
  anchors. When you replace a placeholder, update your spec file.

## Serving from agc

`make panel` (repo root) builds `dist/`, and `go build` embeds it
(`panel/embed.go`). Without a build, agc answers `/panel/` with 503
`control panel not built: run make panel`. `AGC_PANEL_DIR=panel/dist agc …`
serves a build from disk without rebuilding agc.
